# QuickBackup

Простая и предсказуемая утилита резервного копирования файлов и каталогов в
ZIP или TAR. Без зависимостей, без магии: одна команда — один архив, плюс
манифест с контрольной суммой.

```
quickbackup ~/Documents ~/Projects/api -d /mnt/backups --exclude '*.tmp' --keep 14
```

## Возможности

- **Корректный рекурсивный бэкап** каталогов — включая пустые папки;
- ZIP, TAR, `tar.gz`, `tar.xz` (сжатие на выбор);
- **атомарная запись**: архив сначала пишется во временный файл и только потом
  переименовывается — прерванный запуск не оставляет «полуживой» архив;
- **манифест** `<архив>.manifest.json`: размер, SHA-256, количество файлов,
  исходный объём, список пропущенных объектов;
- `--verify` — перечитать архив и сверить с манифестом;
- `--exclude` — исключения по glob (можно несколько);
- `--keep N` — хранить только N последних архивов;
- `--dry-run` — показать план без записи на диск;
- `--json` — машиночитаемый вывод для cron и мониторинга;
- интерактивный режим — если запустить без аргументов;
- понятные коды возврата и аккуратная обработка `Ctrl+C`.

## Установка

Нужен Python 3.9+.

```bash
git clone https://github.com/devilnevecry/QuickBackup.git
cd QuickBackup
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .
```

Или без установки:

```bash
python main.py --help
python -m quickbackup --help     # из корня репозитория
```

## Использование

### Один каталог

```bash
quickbackup ~/Documents -d ~/Backups
```

Результат:

```
Backups/2026-10-23/12-05-31.zip
Backups/2026-10-23/12-05-31.zip.manifest.json
```

### Несколько источников, исключения и ротация

```bash
quickbackup ~/work/site ~/work/api \
  -d /mnt/backups \
  --format tar.gz \
  --exclude '*.log' --exclude 'node_modules' --exclude '.git' \
  --comment nightly \
  --keep 14 \
  --verify
```

Каждый источник попадает в архив под своим именем: `site/...`, `api/...`.

### Автоматизация (cron)

```cron
0 3 * * * /usr/local/bin/quickbackup /srv/app -d /mnt/backups --format tar.gz \
  --exclude '*.log' --keep 30 --verify --json >> /var/log/quickbackup.jsonl 2>&1
```

Пример JSON:

```json
{"status":"ok","archive":"/mnt/backups/2026-10-23/03-00-01.tar.gz","format":"tar.gz",
 "files":1842,"source_bytes":73400320,"archive_bytes":18350080,"sha256":"…",
 "duration_seconds":2.413,"skipped":3,"pruned":["…"],"saved_percent":75.0}
```

### Интерактивный режим

```bash
quickbackup
```

Навигация по каталогам, выбор файлов и папок, удаление из списка, выбор формата
и комментария — тот же сценарий, что был в версии 1.x, но без рекурсии и с
корректным архивом каталогов.

## Опции

| Опция | Описание |
| --- | --- |
| `SOURCES...` | файлы и каталоги для архива |
| `-d, --dest DIR` | куда складывать архивы (по умолчанию `~/Backups`) |
| `-f, --format FMT` | `zip` (по умолчанию), `tar`, `tar.gz`, `tgz`, `tar.xz`, `txz` |
| `-n, --name NAME` | имя архива без расширения |
| `-c, --comment TEXT` | комментарий, добавляется к имени |
| `-x, --exclude GLOB` | исключить пути (можно повторять) |
| `--follow-symlinks` | следовать по симлинкам, с защитой от циклов |
| `--dry-run` | показать, что будет заархивировано |
| `--verify` | проверить архив после создания |
| `--keep N` | оставить N самых новых архивов в `--dest` |
| `--json` | вывести результат в JSON |
| `-q, --quiet` | не писать лог в stderr |
| `--log FILE` | писать лог в файл (ротация 1 МБ × 3) |
| `--version` | версия |

Коды возврата: `0` — успех, `1` — ошибка, `2` — ошибка аргументов, `130` — прерывание.

## Как это работает

1. Источники обходятся **один раз**; список записей и общий размер фиксируются до
   создания архива.
2. Проверяется, что каталог назначения не находится внутри источника (иначе бэкап
   начал бы складывать архивы в себя).
3. Архив пишется во временный файл `.name.part`.
4. Считается SHA-256, формируется манифест.
5. При `--verify` архив перечитывается и сверяется с манифестом.
6. Временный файл атомарно переименовывается в итоговый, рядом появляется манифест.
7. При `--keep` удаляются самые старые архивы и их манифесты.

Симлинки по умолчанию пропускаются (с записью в `skipped`), специальные файлы
(сокеты, FIFO) — тоже. Это поведение можно изменить флагом `--follow-symlinks`.

## Отличия от 1.x

- архивы каталогов теперь действительно содержат файлы (в 1.x ZIP содержал только
  пустые записи каталогов);
- папка назначения больше не может попасть внутрь архива;
- появились CLI, dry-run, verify, манифесты, ротация и JSON;
- атомарная запись вместо «пишем сразу в целевой файл»;
- честный подсчёт размера (раньше для каталогов брался размер inode);
- интерактивный режим сохранён.

Формат архивов совместим с обычными ZIP/TAR — их можно открыть любым архиватором.

## Разработка

```bash
pip install -e '.[dev]'
pytest
ruff check src tests main.py
```

Структура:

```
src/quickbackup/
├── archive.py      # обход источников и запись ZIP/TAR
├── manifest.py     # манифест, SHA-256, проверка
├── retention.py    # ротация архивов
├── interactive.py  # интерактивный режим
└── cli.py          # аргументы и основной сценарий
tests/              # pytest: архивы, манифесты, ротация, CLI, визард
```
